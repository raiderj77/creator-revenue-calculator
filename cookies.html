Cookie Notice

Last reviewed: August 11, 2026

Google AdSense and Microsoft Clarity are disabled. Google Analytics remains blocked until you select "Allow analytics." If allowed, it may set first-party analytics cookies with a pseudonymous client ID and collect the consented usage data described below.

Local storage

The theme control may store a light or dark appearance preference in local storage. The analytics control stores whether you allowed or denied analytics so the choice can be honored on later visits. Local storage is browser data but is not a cookie and is not sent with every web request. You can change analytics permission through the persistent Privacy choices button or remove site data through browser controls.

Hosting technology

Vercel hosts and protects the site. Its infrastructure may use essential technical mechanisms or process routine request data to deliver pages, balance traffic, and prevent abuse. We do not use those mechanisms for behavioral advertising.

External links

The calculator interface does not load icon or chart code from third-party content delivery networks. Following an external or affiliate link creates a normal request to that destination, which may use cookies or storage under its own policy.

Optional analytics cookies and collection

With permission, Google Analytics may use first-party cookies and a pseudonymous client ID to distinguish browsers and sessions. It can receive standard page, session, browser, device, language, screen-resolution, approximate-location, and referrer data. Before Google Analytics is configured, site code strips query strings and fragments from the page-location and referrer values supplied to it.

The site may send generic calculator-completed and result-copied action names after those actions succeed, plus a result-printed action name when the browser print dialog is opened. The site cannot determine whether you complete or cancel printing. Site code does not intentionally add URL query values, calculator inputs or results, copied summaries, email addresses, or other form values to analytics events.

Google Analytics Enhanced Measurement is active and may automatically collect page views, scrolls, outbound clicks, recognized internal site-search terms, file downloads, video engagement, and form interaction metadata. A recognized site-search term may be derived separately by Analytics when a search query is used. Form interaction metadata can indicate that a form was started or submitted; site code does not intentionally add the values typed into a form. Advertising storage, ad personalization, and Google Signals remain disabled. If you continue without allowing analytics, the Google Analytics script is not downloaded and analytics cookies are not set by the site.
