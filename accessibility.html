Accessibility Statement

Last updated: August 2, 2026

Our Commitment

Creator Revenue Calculator is committed to ensuring digital accessibility for people of all abilities. We believe that every content creator, regardless of disability, should be able to access and use our revenue estimation tools. We strive to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 at Level AA, as published by the World Wide Web Consortium (W3C).

Accessibility is an ongoing effort. We review the site during maintenance, document known limitations, and use visitor feedback to identify barriers that automated checks may miss.

Accessibility Features

We have implemented the following accessibility features across our website:

Keyboard Navigation

  • All interactive elements (links, buttons, form inputs, sliders) are accessible via keyboard
  • A logical tab order is maintained throughout each page
  • Focus indicators are visible on all interactive elements when navigating with a keyboard
  • Calculator forms can be fully operated using keyboard controls alone

Screen Reader Compatibility

  • Semantic HTML elements are used to provide meaningful page structure
  • Form labels are properly associated with their input fields
  • Images and icons include appropriate alt text or aria-labels
  • Calculator results are announced to screen readers when calculations are performed
  • Headings are used in a logical hierarchy to aid navigation

Visual Design

  • Our design target is WCAG 2.1 Level AA contrast, including 4.5:1 for normal text and 3:1 for large text
  • We pair color with text labels or other cues in calculator controls and results
  • Responsive layouts are designed to reflow at common mobile widths and browser zoom levels
  • If text resizing or zoom causes content loss, please report the page and browser combination so we can reproduce it

Content and Readability

  • Page language is declared in the HTML lang attribute
  • Content is written in clear, plain language
  • Link text is descriptive and meaningful (avoiding generic "click here" phrases)
  • Calculator inputs use visible labels, numeric constraints, and contextual hints where an input needs explanation

Motion and Animation

  • Animations are minimal and do not include flashing or strobing effects
  • Users who have enabled "prefers-reduced-motion" in their operating system will experience reduced or no animations
  • No content auto-plays or auto-scrolls without user control

Conformance Status

We aim to conform to WCAG 2.1 Level AA. A formal third-party conformance audit has not been completed, so this statement should not be read as a certification. Current implementation measures include:

  • Perceivable: Decorative icons are hidden from assistive technology where appropriate, meaningful controls have accessible names, and result regions use text as well as color.
  • Operable: Calculator inputs and buttons use native keyboard-operable controls, pages provide a skip link, and navigation state is exposed with ARIA.
  • Understandable: Inputs use visible labels and supporting hints, and calculators distinguish arithmetic scenarios from forecasts.
  • Robust: Public pages are checked for valid HTML and JSON-LD during the build, while manual assistive-technology testing remains an ongoing need.

Known Limitations

While we strive for full accessibility, we are aware of the following areas where improvements are ongoing:

  • Visual Resources: Icons and charts are locally hosted. We test the surrounding controls and provide text labels or data summaries where those visuals are not sufficient on their own.
  • Older Browser Support: Some accessibility features may not work optimally in older browsers. We recommend using the latest version of your preferred browser for the best experience.

Assistive Technology Compatibility Target

We have not completed a formal compatibility certification for every screen-reader and browser pairing. The site uses standards-based HTML and targets current versions of:

  • Chrome, Firefox, Edge, and Safari
  • Standards-based screen readers, including NVDA, VoiceOver, TalkBack, and JAWS
  • Keyboard-only and browser-zoom navigation

Compatibility can vary by operating system, browser, assistive-technology version, and page. Please report the exact combination when something does not work.

Feedback and Contact

We welcome your feedback on the accessibility of Creator Revenue Calculator. If you encounter any accessibility barriers, have difficulty using any part of our site, or have suggestions for improvement, please let us know. Reports are reviewed and prioritized based on user impact and reproducibility.

You can reach us at:

  • Email: hello@creatorrevenuecalculator.com
  • Subject line: Accessibility Feedback

When reporting an accessibility issue, please include:

  • A description of the problem you encountered
  • The page URL where the issue occurred
  • The browser and assistive technology you were using
  • Any screenshots or other details that can help us understand and reproduce the issue

We aim to respond to accessibility feedback within 5 business days and to resolve identified issues as quickly as possible.

Enforcement

If you are not satisfied with our response to your accessibility concern, you may file a complaint with your local accessibility enforcement authority or the relevant government body in your jurisdiction.
