What will each estimator mode mean?

Instant mode

Uses currently visible view counts on recent public uploads as a dated proxy. It excludes older-catalog activity and is never labeled actual monthly channel views.

Tracked mode

Remains unavailable until approved daily snapshot storage exists. A 30-day change will require at least 28 valid snapshots and at least a 30-calendar-day span, with missing-snapshot and refresh warnings.

Connected mode

Remains disabled. A future owner-approved release may use Google OAuth and YouTube Analytics, but this initial public-data design contains no OAuth code.
