# Write one evidence-led article draft

Use this command only after an opportunity brief has been approved under `docs/editorial-publishing.md`.

## Draft requirements

1. Lead with the direct answer or workflow the searcher needs.
2. Explain what the related calculator or tracker does and does not calculate.
3. Show formulas and assumptions in plain language.
4. Mark examples as synthetic and make every input user-supplied or explicitly sourced.
5. Cite primary sources beside the claims they support and repeat them in a visible source ledger.
6. Include an honest limitations section and one relevant next action.
7. Use accessible headings, descriptive links, readable tables, and mobile-safe formatting.
8. Record `datePublished`, `dateModified`, source check dates, and a realistic next review date.

## Prohibited

- Invented people, anecdotes, outcomes, testimonials, statistics, rates, or quotes.
- Hidden industry defaults or claims that an example is representative.
- Do not use keyword stuffing, keyword-density targets, fixed minimum word counts, or competitor-length matching.
- “AI signature” tricks, fake firsthand experience, or rewrites intended to evade authorship detection.
- Automatic publication, indexing submission, outreach, or promotion.

Save an unapproved draft outside the public build allowlist. Publication requires a reviewed manifest entry, schema/visible-content parity, full repository checks, and a focused pull request.
