# Research Command

Build a source-linked research brief for one evidence-qualified creator question.

## Usage

`/research [topic]`

## Rules

Read `docs/editorial-publishing.md` first. This command researches; it does not write, publish, merge, deploy, request indexing, promote, contact sources, or spend money.

Do not copy competitor text, structure, tables, examples, or data. Do not fabricate rates, income, quotes, personas, stories, credentials, statistics, search metrics, or platform policies. Do not use word count, keyword density, competitor length, or a fixed number of sources as a quality proxy.

## Workflow

1. Record the opportunity evidence: Search Console query/page metrics and capture date, or a documented user/funnel problem.
2. State the single creator decision or job and the maintained calculator, tracker, or next action that fits it.
3. Search current results to clarify intent and identify unanswered needs. Summarize competitor observations in original words.
4. Gather current primary sources for every planned monetary, percentage, eligibility, fee, formula, and platform-policy claim.
5. Create a claim ledger containing claim ID, exact supported statement, source URL, visible source date when available, checked date, and next review date.
6. Label synthetic examples as examples and derive them only from explicit stated inputs. Record limitations, conflicting sources, and unknowns.
7. Check existing pages, retired routes, and the article registry for cannibalization or a smaller update path.
8. Define the original contribution and a reader-first outline only if the opportunity gate is satisfied.

## Output

Return verified evidence, inferences, unknowns, creator job, intent, primary-source ledger, proposed original contribution, relevant tool/next action, cannibalization check, limitations, and a recommendation to draft, update, defer, or reject.

Do not automatically save. If the user explicitly requests a saved brief, place it under `content/research/` with the capture date and keep it outside the public build.
