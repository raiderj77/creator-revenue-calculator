# Research Topics Command

Group verified queries into creator decisions to find focused opportunities and overlap.

## Usage

`/research-topics [optional date range]`

## Rules

Read `docs/editorial-publishing.md` first. This command is read-only. Do not invent topical-authority scores, demand estimates, coverage quotas, pillar requirements, or a fixed number of supporting articles.

Use the verified Search Console property and record filters, date range, and capture date. Queries with little data may be grouped for exploration but must not be described as demand proof.

## Workflow

1. Collect query/page metrics: clicks, impressions, CTR, and average position.
2. Group queries by shared creator job and compatible search intent; keep ambiguous queries separate.
3. Map each group to existing calculators, trackers, published pages, and retired routes.
4. Identify query cannibalization, missing answer-first explanations, and useful tool-to-content transitions.
5. Check whether primary sources can support the required claims and dates.
6. Recommend the smallest treatment: improve an existing page, research one draft, consolidate, monitor, or reject.

## Output

Return groups with supporting queries, observed metrics, current landing pages, creator decision, evidence confidence, source requirements, overlap risk, and recommended treatment. Do not create a cluster roadmap or publish content.
