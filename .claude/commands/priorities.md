# Priorities Command

Rank current Creator Revenue Calculator opportunities and select one defensible next action.

## Usage

`/priorities [optional focus]`

## Rules

Read `docs/editorial-publishing.md` first. This command is read-only. Do not invent opportunity scores, click forecasts, ranking targets, authority scores, or expected impact.

Use only verified Search Console metrics, verified privacy-safe funnel evidence, current primary sources, observed product defects, and clearly labeled third-party estimates. Missing evidence remains unknown.

## Workflow

1. Verify current repository, production, Search Console, analytics mapping, indexing, and open-work state before treating an observation as actionable.
2. Review homepage and calculator query/page metrics with exact date range and capture date.
3. Consider existing-page CTR/intent improvements, calculator usefulness, conversion friction, trust/source maintenance, technical defects, and only then new articles.
4. Reject duplicate routes, thin query variants, unsupported benchmarks, work already in an open PR, and actions without an honest next step.
5. Rank candidates by evidence strength, creator value, commercial intent, measurable outcome, effort, reversibility, and risk. Explain the comparison instead of collapsing it into an invented number.
6. Select exactly one smallest safe action or identify one genuine blocker.

## Output

Return a compact candidate table with verified evidence, inference, unknowns, effort, risk, and disposition. End with the selected action, validation plan, owner approval needed, and single next best action. Do not draft, edit, publish, merge, deploy, index, contact anyone, or spend money.
