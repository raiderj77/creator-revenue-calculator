# Security Policy

## Supported version

Security fixes are applied to the current `main` branch and the production
deployment built from it.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a suspected vulnerability or include sensitive
information in public discussions.

Include the affected URL or file, reproduction steps, expected impact, and any
suggested mitigation. Reports will be reviewed before public disclosure.

For a privacy concern that is not a software vulnerability, email
privacy@creatorrevenuecalculator.com.
